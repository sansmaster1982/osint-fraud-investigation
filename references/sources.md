# Официальные источники

Перечисленные ниже материалы проверены 2026-10-10. При выполнении кейса проверяй действующую документацию и контакты. Это перечень источников, а не разрешение загружать материалы или отправлять жалобы.

- [urlscan API Documentation](https://urlscan.io/docs/api/) — различие поиска существующих отчётов и создания скана; режимы видимости, лимиты, результат и сохранённый DOM.
- [VirusTotal: How it works](https://docs.virustotal.com/docs/how-it-works) — распространение результатов обычных submissions и доступ к переданным материалам.
- [VirusTotal: Searching](https://docs.virustotal.com/docs/searching) — предупреждение об обработке индикаторов, введённых через веб-интерфейс.
- [VirusTotal: Get a URL report](https://docs.virustotal.com/reference/url-info) — получение существующего URL-отчёта методом GET.
- [VirusTotal: Get a file report](https://docs.virustotal.com/reference/file-info) — получение существующего отчёта по хешу файла.
- [RIPE NCC: How to Find Abuse Contact Information](https://www.ripe.net/languages/en/abuse/) — поиск abuse-контактов и границы роли RIPE NCC.
- [ICANN: Submitting a Complaint to Contractual Compliance](https://www.icann.org/compliance/complaint?a=r) — назначение и область процедур договорного надзора.

Скилл адаптирован из пользовательской инструкции по разбору фишинг-ссылок. Перенесены поиск публичных технических сведений, анализ сохранённых материалов, журнал, отчёт и подготовка обращений. Исходные документы, примеры реальных кейсов, личные сведения и локальные пути в пакет не входят.

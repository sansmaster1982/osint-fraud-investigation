# OSINT: расследование мошеннической инфраструктуры

Скилл для Codex: разбор подозрительных ссылок и сайтов по открытым техническим источникам и сохранённым материалам. Результат — подтверждённые наблюдения, журнал доказательств, индикаторы и отчёт. По поручению пользователя готовит черновики обращений.

## Что входит

- Проверка DNS, RDAP, сетевых ресурсов, истории доменов и сертификатов.
- Анализ существующих отчётов и сохранённого HTML/JS без исполнения кода.
- Фиксация источников и времени наблюдения, локальный SHA-256 файлов.
- Шаблон отчёта и подготовка обезличенных обращений.

Выводы привязаны к доказательствам. Общий IP не используется для идентификации людей или объявления всех соседних сайтов одной кампанией. Отправка жалоб и передача материалов внешним сервисам выполняются только в пределах прямого поручения пользователя.

Скилл не предназначен для деанонимизации частных лиц, слежки, работы с утечками, активных атак и запуска неизвестного кода. Персональные данные и секреты не входят в публичный пакет.

## Установка

Для PowerShell с установленным Git:

```powershell
$OsintSkillRoot = if ($env:CODEX_HOME) { Join-Path $env:CODEX_HOME 'skills' } else { Join-Path $env:USERPROFILE '.codex\skills' }
New-Item -ItemType Directory -Path $OsintSkillRoot -Force | Out-Null
git clone https://github.com/sansmaster1982/osint-fraud-investigation.git (Join-Path $OsintSkillRoot 'osint-fraud-investigation')
```

Если папка скилла уже существует, сначала проверь её содержимое. После установки открой новый чат Codex, если скилл ещё не появился в списке.

## Использование

```text
Используй $osint-fraud-investigation. Разбери подозрительный домен
по открытым источникам и моим сохранённым материалам. Подготовь
отчёт и таблицу индикаторов. Жалобы пока только черновиками.
```

Для режима без сети:

```text
Используй $osint-fraud-investigation. Проанализируй только приложенные
HTML и отчёты, без сети и создания файлов. Дай подтверждённые наблюдения
и укажи, что установить по этим материалам нельзя.
```

Локальный вспомогательный скрипт работает на Python 3.12 без сторонних библиотек. Из папки скилла, после создания папки `manifests` рядом с `evidence`:

```powershell
python -X utf8 .\scripts\evidence_manifest.py "CASE_DIR\evidence" --output "CASE_DIR\manifests\evidence-001.csv"
```

`CASE_DIR` заменяется абсолютным путём к кейсу. Скрипт не использует сеть и не перезаписывает существующий результат. Манифест фиксирует контрольные суммы; он не удостоверяет истинность сохранённого содержания.
